Capitulo 9 de 16

La versión de ingeniería: el modelo físico

Documenta el modelo físico: coordenadas, tiempo, salida del plato, plomeo, energía residual y detección de impacto.

Como leer este capitulo

Tirador: busca las ideas practicas y las senales que puedes observar en cancha.

Simulador: relaciona cada concepto con controles, ayudas visuales y ejercicios repetibles.

Tecnica: usa las formulas y limites como apoyo, no como sustituto de profesor o normativa.

Este capítulo se escribirá después de revisar el código real. El índice define qué debe documentarse, pero no presupone todavía la implementación exacta.
