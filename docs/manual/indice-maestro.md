# Índice maestro extendido del manual HTML

Mantendría los **16 capítulos principales**, pero cada uno tendría una estructura interna suficientemente detallada para convertirlo después en texto, capturas, diagramas, infografías y documentación técnica.

## Estructura común de los capítulos

Para que el manual sirva tanto a un tirador como a una persona técnica, cada capítulo podrá combinar cinco capas:

* **Explicación para el tirador:** lenguaje sencillo, ejemplos de campo y pocas fórmulas.
* **Qué debe observar:** señales visuales, errores frecuentes y decisiones prácticas.
* **En el simulador:** relación directa con controles, parámetros y escenarios de la aplicación.
* **Visión técnica:** geometría, física, unidades, algoritmos o decisiones de diseño.
* **Fuentes y límites:** referencias, normativa y advertencias cuando corresponda.

No todos los capítulos necesitarán las cinco, pero este será el patrón editorial general.
