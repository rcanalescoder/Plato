Fuentes, glosario, preguntas frecuentes y control documental

Reúne fuentes, glosario, preguntas frecuentes y control documental para mantener la solvencia del proyecto.

Como leer este capitulo

Tirador: busca las ideas practicas y las senales que puedes observar en cancha.

Simulador: relaciona cada concepto con controles, ayudas visuales y ejercicios repetibles.

Tecnica: usa las formulas y limites como apoyo, no como sustituto de profesor o normativa.

# Elementos preliminares del manual

Estos elementos aparecerían antes del capítulo 1, pero no cuentan como capítulos adicionales:

  • Portada.
  • Subtítulo del proyecto.
  • Captura principal del simulador.
  • Aviso de seguridad.
  • Aviso sobre la naturaleza educativa.
  • Navegación por perfiles:

* «Estoy empezando».

* «Ya soy tirador».

* «Quiero entender la física».

* «Quiero instalar o modificar el proyecto».

  • Índice general.
  • Buscador.
  • Botón de acceso al simulador.

# Elementos transversales del HTML

El manual completo debería incorporar:

  • Navegación lateral por capítulos.
  • Índice desplegable.
  • Barra de progreso de lectura.
  • Modo claro y oscuro, si se considera conveniente.
  • Ampliación de infografías.
  • Capturas con puntos interactivos.
  • Glosario emergente.
  • Fórmulas desplegables.
  • Pestañas «Explicación sencilla» y «Visión técnica».
  • Calculadora de costes.
  • Escenarios enlazados con el simulador.
  • Botón para volver a la aplicación.
  • Referencias al final de cada capítulo.
  • Versión imprimible.
  • Diseño adaptable a móvil, tableta y escritorio.

Este sería el índice maestro de referencia. A partir de él, cada texto, infografía, captura o cambio de código deberá asociarse a un número concreto, evitando que Codex improvise una documentación breve o deje contenidos importantes fuera.
