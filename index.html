Manual vivo + laboratorio visual

Entender el adelanto antes de gastar cartuchos.

Plato combina un simulador HTML de tiro al plato con un manual pedagogico por capitulos. La idea es explicar al tirador que ve, por que falla, como leer el plato y como relacionar esa intuicion con fisica, plomeo, cartucho, distancia y modalidad.

Arrancar el simulador Ver indice del manual

Una documentacion para tiradores y para gente tecnica

Para empezar

Lenguaje de campo

Primero se explica lo que nota el tirador: el plato aparece, la escopeta estorba si se tapa el objetivo, el swing se para, el disparo llega tarde o bajo.

Para entrenar

Ejercicios repetibles

Despues se conecta cada idea con el simulador: repetir plato, ocultar ayudas, comparar tiro 1 y tiro 2, variar plomeo, camara lenta y robot.

Para auditar

Modelo fisico visible

La parte tecnica documenta coordenadas, velocidades, alcances, energia residual, cuerda de perdigones, chokes y limites del modelo.
